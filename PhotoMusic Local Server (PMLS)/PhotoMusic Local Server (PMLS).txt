# 🟦 3. COMO INTEGRAR DSLBoot E LumaBoot

Essa parte é **muito simples**, porque ambos os softwares permitem:

- enviar fotos para uma pasta  
- enviar fotos para FTP  
- enviar fotos para um servidor HTTP  

### ✔ Opção 1 — Pasta compartilhada (mais simples)
Você cria no servidor local:

```
\\PHOTOMUSIC-SERVER\cabine
```

E configura o DSLBoot/LumaBoot para salvar lá.

### ✔ Opção 2 — FTP local
Instala um servidor FTP no mini PC:

- FileZilla Server  
- IIS FTP (Windows)  
- ProFTPd (Linux)  

Configura:

```
Host: 192.168.0.10
User: photomusic
Pass: ******
Pasta: /uploads
```

### ✔ Opção 3 — API HTTP local (mais profissional)
O servidor local roda uma API:

```
POST http://192.168.0.10/upload
```

O DSLBoot/LumaBoot envia as fotos/vídeos direto para o sistema.
