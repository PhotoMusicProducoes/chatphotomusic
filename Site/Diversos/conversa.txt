# 🧭 Visão Geral do Sistema ChatBot PhotoMusic Pro

O **ChatBot PhotoMusic Pro** é um sistema avançado de atendimento automatizado para WhatsApp, criado para:

- Atender clientes automaticamente  
- Coletar informações do evento  
- Gerar orçamentos personalizados

- Seleção automática de PDF por duração  
- Seleção automática por tipo de evento  
- Seleção automática por número de convidados  
- Seleção automática por dias (corporativo)  
- Envio de PDF + link direto  
- Observação de deslocamento  
- Mensagens finais de encerramento  

## 5) **Comandos manuais do operador**

```

retomar 5521999999999

- Forçar envio de orçamento  
- Enviar múltiplos serviços  
- Pausar cliente  
- Retomar cliente  
- Resetar atendimento  
- Definir cliente manualmente  

## 6) **Controle de duplicidade**
O sistema impede que a mesma mensagem seja processada duas vezes.

## 7) **Controle de pausa**
Quando pausado:

- O cliente pode enviar mensagens  
- Mas o bot não responde  
- O operador pode responder manualmente

public static function render_relatorio() {
    global $wpdb;

    $eventos = $wpdb->get_results("SELECT id, motivo_evento, data_evento FROM {$wpdb->prefix}pm_eventos ORDER BY data_evento DESC");

    echo '<div class="wrap"><h1>Relatório de Aceites</h1>';

    foreach ($eventos as $evento) {

        echo "<h2>Evento: {$evento->motivo_evento} ({$evento->data_evento})</h2>";

        $aceites = $wpdb->get_results(
            $wpdb->prepare(
                "SELECT * FROM {$wpdb->prefix}pm_aceites
                 WHERE id_evento = %d
                 GROUP BY telefone, email
                 ORDER BY aceite_em DESC",
                $evento->id
            )
        );

        if (!$aceites) {
            echo "<p>Nenhum aceite registrado.</p>";
            continue;
        }

        echo '<table class="widefat striped">';
        echo '<thead><tr>
                <th>Nome</th>
                <th>Telefone</th>
                <th>Email</th>
                <th>IP</th>
                <th>Dispositivo</th>
                <th>Navegador</th>
                <th>Data do Aceite</th>
              </tr></thead><tbody>';

        foreach ($aceites as $a) {
            echo "<tr>
                    <td>{$a->nome}</td>
                    <td>{$a->telefone}</td>
                    <td>{$a->email}</td>
                    <td>{$a->ip}</td>
                    <td>{$a->dispositivo}</td>
                    <td>{$a->navegador}</td>
                    <td>{$a->aceite_em}</td>
                  </tr>";
        }

        echo '</tbody></table><br><hr>';
    }

    echo '</div>';
}
```

### 1.2 Crie a função de exportação CSV no final da classe

**Onde:** no final do arquivo, **antes do último `}`** da classe `PhotoMusic_Painel_Contratante`.

**Cole:**

```php
public static function processar_export_csv_aceites() {

    if (empty($_GET['pm_export_aceites']) || $_GET['pm_export_aceites'] !== '1') return;
    if (empty($_GET['evento'])) wp_die('Evento não informado.');

    $id_evento = intval($_GET['evento']);

    // Só contratante logado pode exportar
    if (!PhotoMusic_Contratante::is_logged_in($id_evento)) {
        wp_die('Acesso não autorizado.');
    }

    // Nonce
    if (empty($_GET['_wpnonce']) || !wp_verify_nonce($_GET['_wpnonce'], 'pm_export_aceites_' . $id_evento)) {
        wp_die('Falha de segurança (nonce).');
    }

    global $wpdb;

    $aceites = $wpdb->get_results(
        $wpdb->prepare(
            "SELECT * FROM {$wpdb->prefix}pm_aceites
             WHERE id_evento = %d
             GROUP BY telefone, email
             ORDER BY aceite_em DESC",
            $id_evento
        )
    );

    $filename = 'aceites-evento-' . $id_evento . '-' . date('Y-m-d_H-i') . '.csv';

    header('Content-Type: text/csv; charset=utf-8');
    header('Content-Disposition: attachment; filename=' . $filename);

    $out = fopen('php://output', 'w');

    // Cabeçalho
    fputcsv($out, [
        'Evento ID',
        'Nome',
        'Telefone',
        'Email',
        'IP',
        'Dispositivo',
        'Navegador',
        'Sistema Operacional',
        'Idioma',
        'Canal Origem',
        'Aceite em'
    ]);

    foreach ($aceites as $a) {
        fputcsv($out, [
            $id_evento,
            $a->nome,
            $a->telefone,
            $a->email,
            $a->ip,
            $a->dispositivo,
            $a->navegador,
            $a->sistema_operacional,
            $a->idioma_navegador,
            $a->canal_origem,
            $a->aceite_em
        ]);
    }

    fclose($out);
    exit;
}
```
