## Exemplos de uso

```
#fotoeucaristia 1,3,27/04/2026
```
→ Paróquia São José · Capela Nossa Senhora de Bonsucesso · 27/04/2026

```
#fotoeucaristia 2,1,05/04/2026
```
→ Paróquia São Sebastião · Matriz São Sebastião · 05/04/2026

```
#fotoeucaristia 1,5,10/05/2026 -> 5521999999999
```
→ Envia para número específico (Paróquia São José · Capela Santo Antônio)

---

## Observações
- A data deve ser informada no formato `dd/mm/yyyy` usando barras (/)
- Para enviar para um cliente específico, use `-> número` no final
- O sistema identifica automaticamente o prazo de pagamento conforme a paróquia
