========================================================
🎯 DEFINIR CLIENTE MANUALMENTE
========================================================

Use quando:
- o cliente veio de LID
- o bot não identificou o número
- você quer enviar orçamento manual para um cliente específico
- você quer garantir que o orçamento vá para o número certo

COMANDO:
#cliente [número]

Aceita qualquer formato:
#cliente 5521993290588
#cliente 55 21 993290588
#cliente +55 21 99329-0588
#cliente 21 99329-0588
#cliente 21993290588

Exemplo:
#cliente 5521967082501


========================================================
🧹 LIMPAR CLIENTE MANUAL
========================================================

Use quando quiser voltar ao modo automático:
#limparcliente


========================================================
🎯 COMANDOS DE ORÇAMENTO MANUAL
========================================================

FORMATO GERAL:
#[serviço] [avaliação],[celebração],[convidados],[horas],[dias]

PARÂMETROS:
1. avaliação → 0 (não envia) ou 1 (envia)
2. celebração → ID do evento (tabela abaixo)
3. convidados → número de convidados
4. horas → duração do serviço
5. dias → dias (somente corporativo; padrão = 1)


========================================================

4 - Aniversário Adolescente

6 - Bodas
